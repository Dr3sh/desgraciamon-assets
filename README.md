# DesgraciaMon Assets

Repositorio oficial de assets dinámicos y animaciones de pantalla para el servidor **DesgraciaMon 4**.

## Estructura
- nimations/manifest.json: Índice maestro que los clientes leen al conectarse para descargar o retirar animaciones.
- nimations/<nombre>.zip: Paquete con nimation.json, frames y audio opcional.
